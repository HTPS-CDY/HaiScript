HaiScript v1.2.0

轻量级脚本语言与命令行工具箱。类 Python 语法、双后端原生编译、完全自包含的汇编工具链、内置包管理器、零第三方依赖。

⬇️ 下载 haiscript.tar（直接运行 EXE） GitHub 主仓库 📦 包仓库 HSLib 📄 文档 README 全部 Releases

核心特性

💻 交互式 Shell
文件 / 系统 / 网络 / 编码命令，一站式操作。
📝 HaiScript (.hs)
类 Python 语法，变量 / 函数递归 / 字符串 / 列表 / Map / Set / try-catch / 类型注解。
⚡ 双后端编译
C 后端 (GCC)，汇编后端 NASM + lld-link，完全自包含，零外部依赖。
📦 标准库
json / path / os / math / pic(图片) / touch(外部调用) / http(内网) / lan(局域网)。
🧩 包管理器 hsinser
从 HSLib 仓库一键下载安装扩展包：hsinser install xxx。
🛠️ 开发工具
fmt 格式化 / typecheck 渐进式类型检查 / IR 中间表示 + 常量折叠优化。

快速开始

交互式 Shell

git clone https://github.com/HTPS-CDY/HaiScript.git
cd HaiScript
python -m haiscript.main

常用命令

# 执行脚本
python -m haiscript.main run demo.hs

# 编译为原生 EXE（汇编后端，零外部依赖）
python -m haiscript.main compile demo.hs demo.exe --asm

# 语法检查 / 格式化 / 类型检查
python -m haiscript.main check demo.hs
python -m haiscript.main fmt demo.hs -i
python -m haiscript.main typecheck demo.hs

# 安装扩展包
python -m haiscript.main hsinser install mypkg
python -m haiscript.main hsinser list

依赖工具下载

汇编后端已完全自包含（内置 haiscript/asm/ 目录下所有工具和 DLL），仅 C 后端需 GCC。推荐下载：

🚀 haiscript.tar（直接运行 EXE）

内含打包好的 haiscript.exe，无需安装 Python、无需编译。解压即用，汇编后端（NASM + lld-link）已完整嵌入。

⬇️ 下载 haiscript.tar 推荐：Windows 64 位直接运行版

🖥️ GCC（C 后端需要）

MinGW-w64 GCC for Windows，用于 .hs → C → EXE 编译链路。

⬇️ 下载 MinGW-w64 推荐 x86_64-ucrt-posix-seh

🔧 NASM（已内置）

汇编后端已将 nasm.exe 及所有依赖 DLL 内置到 haiscript/asm/，无需安装。

NASM 官网 已内置，免下载

🔗 LLVM lld-link（已内置）

链接器已内置到 haiscript/asm/（含 libLLVM-22.dll 等 9 个依赖）。

LLVM Releases 已内置，免下载

🐍 Python 3.10+

（源码版需要）纯标准库即可运行；下载 haiscript.tar 则无需此步。

⬇️ 下载 Python 推荐 3.12.x

✅ 自包含校验（汇编后端）

以下工具与 DLL 已内置到 haiscript/asm/，无需任何外部安装：
